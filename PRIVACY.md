# NovusVision privacy policy

Novus Mercatura publishes NovusVision for Windows. The app processes its desktop features on the device.

## What the app processes

- The fog overlay reads the cursor coordinates to position the clear or darkened area. It draws an overlay using Windows graphics.
- When you enable Click Guard, the app uses covered mouse input and asks Windows for the control at the clicked location. The prompt can show the application title and a label supplied by Windows accessibility. The app uses that information in memory to review, cancel, or deliver the pending click.
- Settings, saved profiles, and keyboard shortcuts are stored on the device. If you enable Start with Windows, NovusVision registers with Windows to open at sign-in.

NovusVision sends no cursor positions, click data, screen content, or settings to Novus Mercatura or other services. It includes no analytics, advertising, or click history. Choosing the Novus Mercatura link opens your web browser.

You can turn the overlay and Click Guard off separately, clear your saved default in the app, and delete its preferences from the local application data folder. Windows manages Store installations and updates according to Microsoft's policies.

For privacy questions, contact [Novus Mercatura](https://novusmercatura.com).
